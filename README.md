# Kunal Kumar — Portfolio

React 19 + Vite. All content is in `src/data.js`; edit that to update the site.

## Setup
```
npm install
cp .env.example .env   # add your Web3Forms key for the contact form
npm run dev
```

Put your resume PDF at `public/resume/Kunal_Kumar_Resume.pdf` (the "Resume" button links there).
